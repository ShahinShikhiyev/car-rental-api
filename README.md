# Car Rental API 🚗

Bun, Express.js və MongoDB istifadə olunaraq hazırlanmış Avtomobil İcarəsi backend layihəsi.

## İşlədilən Texnologiyalar
- **Runtime:** Bun
- **Framework:** Express.js
- **Database:** MongoDB (Mongoose)
- **Auth:** JWT (`jsonwebtoken`, `bcryptjs`)
